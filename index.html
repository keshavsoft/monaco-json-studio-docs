Composable HTML Building Blocks for Monaco Studios

Rather than hiding hardcoded HTML inside one monolithic generator, the Monaco JSON Studio suite separates every page into three .hbs-driven region primitives (Header, Body, Footer) composed directly by Single, Double, and Triple.

Tier 1: Region Primitives (.hbs + Runtime)

monaco-json-studio-base-header

title, file-picker, select, and actions headers built with Handlebars & dom-primitive-bindings.

Docs npm GitHub

monaco-json-studio-base-body

single, double, and triple workspace .hbs layouts with Monaco mounting helpers.

Docs npm GitHub

monaco-json-studio-base-footer

cursor, note, status, and stats footers with live cursor & JSON validation updaters.

Docs npm GitHub

Tier 2: Composed Studios (v2)

monaco-json-studio-single

1-pane studio combining base-header + base-body (single) + base-footer.

Docs npm GitHub

monaco-json-studio-double

2-pane studio combining base-header + base-body (double) + base-footer.

Docs npm GitHub

monaco-json-studio-triple

3-pane studio combining base-header + base-body (triple) + base-footer.

Docs npm GitHub
