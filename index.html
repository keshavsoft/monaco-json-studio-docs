1-, 2-, and 3-Pane Static Monaco JSON Studios

Each Studio package focuses on one layout—Single, Double, or Triple—and assembles its HTML directly from the three Base Region Primitives using a clean document.hbs shell.

The 3 Studio Packages

monaco-json-studio-single

1-pane studio combining base-header + base-body (single) + base-footer.

Overview Repo Docs npm GitHub

monaco-json-studio-double

2-pane studio combining base-header + base-body (double) + base-footer.

Overview Repo Docs npm GitHub

monaco-json-studio-triple

3-pane studio combining base-header + base-body (triple) + base-footer.

Overview Repo Docs npm GitHub

How Studios Compose Base Regions

Single / Double / Triple (document.hbs + active-pane runtime)
   ├── monaco-json-studio-base-header
   ├── monaco-json-studio-base-body
   └── monaco-json-studio-base-footer

To explore or extend the underlying .hbs regions, visit Monaco JSON Studio Base Docs.
