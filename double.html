monaco-json-studio-double

A dedicated 2-pane side-by-side Monaco JSON Studio where Pane 1 and Pane 2 each have independent headers and footers.

View on npm GitHub Repo Repo Docs

Why This Repo Exists

When comparing two JSON payloads—or pairing an input file with a transformed output—each pane needs its own header controls and status footer while the global studio bar stays fixed.

CLI Usage

npx monaco-json-studio-double
npx monaco-json-studio-double file-picker:cursor select:note
npx monaco-json-studio-double title:none

Outputs to ./monaco-double-<pane1>_<pane2> with automatic non-overwriting folder suffixes.

Programmatic API

import { createDoubleStudio } from 'monaco-json-studio-double';

createDoubleStudio({ pane1: 'file-picker:cursor', pane2: 'select:note' });
