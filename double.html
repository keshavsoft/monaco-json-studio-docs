monaco-json-studio-double

2-pane studio directly composing base-header + base-body (double) + base-footer, with active-pane tracking so top-bar actions target whichever editor is focused.

View on npm GitHub Repo Repo Docs

CLI Usage

npx monaco-json-studio-double
npx monaco-json-studio-double file-picker status
npx monaco-json-studio-double select stats
npx monaco-json-studio-double actions cursor

Outputs to ./monaco-double-<header>-<footer> with automatic non-overwriting folder suffixes.

Programmatic API

import { createDoubleStudio } from 'monaco-json-studio-double';

createDoubleStudio({ header: 'file-picker', footer: 'status' });
