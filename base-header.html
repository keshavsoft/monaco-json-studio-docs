monaco-json-studio-base-header

Handlebars (.hbs) header components paired with dom-primitive-bindings (bindings.json + actions.js) for file picking, dataset selection, titles, and action buttons.

npm Package GitHub Repo Repo Docs

Why This Repo Exists

Headers evolve rapidly—plain titles, file pickers, dataset dropdowns, format/copy toolbars. Extracting them into assets/v1/templates/*.hbs keeps HTML out of JS and lets Single, Double, and Triple reuse the exact same header blocks.

CLI & API

npx monaco-json-studio-base-header file-picker
npx monaco-json-studio-base-header select
npx monaco-json-studio-base-header actions --html
import { renderHeader } from 'monaco-json-studio-base-header';
const html = renderHeader({ type: 'file-picker', label: 'JSON Studio' });
