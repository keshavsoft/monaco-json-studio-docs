monaco-json-studio-single

A dedicated 1-pane studio generator. Because it knows there is only one editor, it places Select File or dataset dropdowns directly inside the top studio header.

View on npm GitHub Repo Repo Docs

Why This Repo Exists

In a 1-pane layout, stacking a separate pane header directly underneath the main studio bar wastes vertical space. monaco-json-studio-single eliminates the extra bar by moving header controls up into .studio-header and removing pane-count flags entirely.

CLI Usage

npx monaco-json-studio-single
npx monaco-json-studio-single file-picker cursor
npx monaco-json-studio-single select note
npx monaco-json-studio-single title none

Outputs to ./monaco-single-<header>-<footer> (and appends -1, -2, … if the directory already exists).

Programmatic API

import { createSingleStudio } from 'monaco-json-studio-single';

createSingleStudio({ header: 'file-picker', footer: 'cursor' });
