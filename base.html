monaco-json-studio-base

The shared primitive engine and browser runtime behind Single, Double, and Triple—built so Monaco loading, CSS, and DOM event wiring live in one place.

View on npm GitHub Repo Repo Docs

Why This Repo Exists

Splitting into Single, Double, and Triple works only if you do not copy-paste Monaco setup, CSS, and HTML builders three times. monaco-json-studio-base owns the shared engine and stays completely agnostic about how many panes a wrapper renders.

3-Region Architecture

src/v1/
├── header/          # title, file-picker, select, none (top-bar or per-pane placement)
├── body/            # monaco editor mount & language config
├── footer/          # cursor, note, none
└── generateStudio.js # builds index.html, state.js, data/, css/, and js/

Browser DOM events (Select File, file input change, dataset <select>) are wired declaratively via dom-primitive-bindings (header/bindings.json + header/actions.js), while Monaco's instance callbacks update cursor position in footer/cursor.js.

Programmatic Usage

import { generateStudio } from 'monaco-json-studio-base';

generateStudio({
  title: 'Custom Studio',
  outputDir: './my-studio',
  panes: [
    { key: 'pane1', label: 'Pane 1', header: 'file-picker', body: 'monaco', footer: 'cursor' }
  ]
});
