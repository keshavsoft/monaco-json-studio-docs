monaco-json-studio-base-footer

Handlebars (.hbs) footer components (cursor.hbs, note.hbs, status.hbs, stats.hbs) paired with live cursor and JSON stats updaters.

npm Package GitHub Repo Repo Docs

Why This Repo Exists

Footers display live editor feedback (cursor Ln/Col, JSON validity, line/character counts, and status notes) cleanly separated from Header and Body.

CLI & API

npx monaco-json-studio-base-footer cursor
npx monaco-json-studio-base-footer stats
npx monaco-json-studio-base-footer status --html
import { renderFooter } from 'monaco-json-studio-base-footer';
const html = renderFooter({ type: 'stats', lines: 12, chars: 240 });
