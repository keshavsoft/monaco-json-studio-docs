monaco-json-studio-preview

Clean Bootstrap 5 DOM target (Tab 2) that receives live JSON from monaco-json-studio-single over BroadcastChannel and compiles it via @keshavsoft/json-to-dom.

Repo Docs npm Package GitHub Repo

2-Tab Live Workflow

mkdir test-v5 && cd test-v5
npx monaco-json-studio-single file-picker cursor --url https://keshavsoft.github.io/declarative-spec/json/v3/spec.json
npx monaco-json-studio-preview
npx serve

Open /monaco-single-file-picker-cursor/ in Tab 1 and /monaco-preview/ in Tab 2, then click Render in Tab 1.
