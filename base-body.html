monaco-json-studio-base-body

Handlebars (.hbs) 1-, 2-, and 3-pane workspace templates (single.hbs, double.hbs, triple.hbs, pane.hbs) paired with the Monaco mounting runtime.

npm Package GitHub Repo Repo Docs

Why This Repo Exists

Isolating the body workspace allows one shared Header and one shared Footer to wrap 1, 2, or 3 panes—and makes it easy to swap Monaco for HTML previews, tables, or diff views later.

CLI & API

npx monaco-json-studio-base-body single
npx monaco-json-studio-base-body double
npx monaco-json-studio-base-body triple --html
import { renderBody } from 'monaco-json-studio-base-body';
const html = renderBody({ layout: 'triple' });
