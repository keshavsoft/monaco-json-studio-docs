monaco-json-studio-triple

A dedicated 3-pane static Monaco JSON Studio built for Input → Spec/Rules → Output workflows.

View on npm GitHub Repo Repo Docs

Why This Repo Exists

Three-pane tools (like source JSON + transformation rules + generated output) have distinct defaults per column. Isolating Triple into its own package keeps the CLI direct and lets each pane declare its own header:footer pair.

CLI Usage

npx monaco-json-studio-triple
npx monaco-json-studio-triple file-picker:cursor select:cursor title:note
npx monaco-json-studio-triple file-picker:cursor

Outputs to ./monaco-triple-<pane1>_<pane2>_<pane3> with automatic non-overwriting folder suffixes.

Programmatic API

import { createTripleStudio } from 'monaco-json-studio-triple';

createTripleStudio({
  pane1: 'file-picker:cursor',
  pane2: 'file-picker:cursor',
  pane3: 'title:note'
});
